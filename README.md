# Schwarz-Gelbe Heimat

Private, inoffizielle Dynamo-Fan-App als statische GitHub-Pages-Web-App.

## Funktionen

- mobile schwarz-gelbe Oberfläche
- Spielplan und Ergebnisse über OpenLigaDB
- Live-Center
- lokales Tippspiel
- privater Fan-Ticker auf dem eigenen Gerät
- bearbeitbares Fanprofil
- responsive Nutzung ohne App Store

## Veröffentlichung

Die App wird automatisch über GitHub Pages veröffentlicht. In den Repository-Einstellungen unter **Pages** muss als Quelle **GitHub Actions** ausgewählt sein.

## Rechtlicher Hinweis

Dies ist eine private, inoffizielle Fan-App. Keine Verbindung zur SG Dynamo Dresden oder deren offiziellen Angeboten. Es werden keine offiziellen Logos oder redaktionellen Inhalte verwendet.
